## 这是什么

**配置中心**是项目的管理面板。入口两个：右上角头像菜单 →「配置中心」，或左侧栏底部的「配置中心」。进去之后左侧栏换成管理面板的菜单，顶部多一个「返回项目」。

谁能进：项目所有者、制作人，以及被单独授了管理面权限的人。普通成员看不到入口。

![配置中心 · 项目概览](/manual/admin/overview.png)

## 怎么操作

### 项目概览

第一页是概览：成员数、部门数、角色数、里程碑数、公告数，下面是项目信息（名称、所有者、类型、语言、创建时间、状态、简介）。

### 菜单

| 分组 | 页面 |
|---|---|
| 项目发布 | 里程碑 · 公告管理 |
| 组织架构 | 成员与部门 · 角色管理 |
| 安全设置 | 权限中心 · 权限模版 · 策略中心 |
| 合规 | 权限审计 · 数字资产审查 |
| 项目设置 | 项目信息 · 管理员设置 · 数据迁移 · 危险操作 |

权限中心和策略中心是**专业档**功能，免费档项目的菜单里没有这两项。

### 第一次进：激活管理权限

刚被任命为制作人的人第一次进配置中心，会弹出激活窗口列出管理面的权限，点「一键激活」。和加入项目时那一次是同一回事。

## 注意事项

- 配置中心的改动大多**立即生效**、没有「保存草稿」，尤其是权限和策略。改之前想清楚影响的是谁。
- 有些操作只有项目所有者能做（转让、删除、兑换升级码、任命制作人），制作人看得到但按钮是灰的。

## 常见问题

**我是制作人，为什么进不了配置中心？**
任命之后要你本人「一键激活」一次。刷新页面看有没有弹窗；没有的话让所有者到「管理员设置」里确认任命成功。
