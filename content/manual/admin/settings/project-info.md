## 这是什么

「配置中心 → 项目信息」是项目的基本资料页，加上三块独立的设置。

## 怎么操作

### 基本信息

- **项目名称**：显示在项目列表和配置中心标题栏。
- **项目头像**：JPG / PNG / WebP，最大 5 MB，显示在项目列表和顶栏。
- **项目简介**：一两句话，显示在项目首页。
- **项目类型**：话剧 / 音乐剧 / 舞剧……
- **语言**：展示用。

每项单独「保存」。没有对应权限的项按钮是灰的。

### 安全：页面水印

打开「启用水印」后，项目内所有页面平铺显示访问者的姓名和邮箱作水印，截图能溯源。不影响操作；打开后刷新页面生效。打印导出的 PDF 也带。

### 成员标签

系统标签（正式 / 副 / 助理 / 外包 / 实习 / 顾问）不可删；这里可以「创建」项目自己的标签（比如「首演周到场」），在成员详情里打。标签只是标注，不影响权限。

### 项目档位

显示当前档位、成员数 / 上限、AI 助手和高级权限配置是否开通。项目所有者在这里贴**项目升级码**「兑换」，升到专业档。其他人看得到，兑换框不给用。

## 注意事项

- 水印是给「防外泄」用的，对成员有心理成本——排练期开、创作期关是常见做法。
- 改项目名不影响任何链接和数据。
