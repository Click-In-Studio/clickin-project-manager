## 这是什么

审批中心是当前项目的审批工作台，把权限申请和费用报销放在同一处查找、处理。它只显示这个项目内与你有关的实例，不会把其他项目的敏感审批混进来。

入口：项目内左侧栏「审批」，页面标题是「审批中心」。遇到没有权限时，也可以在被拦住的地方直接点「申请访问」；报销仍从「财务」发起。

先按你与流程的关系切换 **待我处理 / 我已处理 / 抄送我的 / 我的申请**，再用 **全部 / 权限申请 / 费用报销** 缩小类型。待办按最早提交优先，其余视图按最新记录优先。点一条记录后，桌面端在右侧、手机端在独立详情层展示业务字段、流程记录和当前真实可执行的操作。

手机上申请与审批按卡片排列，点一张卡片会打开独立详情层；顶部「返回」回到原列表，底部操作区不会被导航栏遮住。

## 怎么操作

### 发起申请

1. 「申请资源权限」（或在被拦的页面点「申请访问」）。
2. 选**资源类型**（剧本、章节/段落、事件、Cue表、数字资产、任务、成员……）和具体哪一个（或全部）。
3. 选**权限级别**：查看 / 编辑 / 管理，个别类型还有发布、创建、删除、挂载。
4. 选**有效期**：1 周 / 30 天 / 180 天 / 长期 / 自定义日期。
5. 写申请理由（选填但有助于快速批准），「提交申请」。

提交后能看到标题、状态、申请人、提交时间、申请内容、当前节点、后续升级路径和完整审批记录。申请没结果前，申请人可以「撤回申请」。

### 谁来批（默认阶梯）

没有配流程模版时，申请沿这条阶梯走，每一级 **24 小时**没人处理自动升到下一级：

1. 你的直属上级（他自己得有这项权限才能终局批准，否则只能转交）
2. 这个资源的持有者（比如那张 Cue 表的创建者）
3. 权限中心「资源审批人」里配的共管部门 POC 或个人
4. 上一级部门的 POC，逐级向上
5. 制作人
6. 项目所有者（必然存在，最终兜底）

前面已经通知过的人不会在后面重复出现。有几类敏感权限跳过整条链直达所有者；根级权限（转让、删除这种）不接受申请。

### 审批

「待我处理」列出等你决定的申请。选中一条看申请人、业务字段、当前节点和处理记录。详情底部只显示你此刻真实能执行的操作：权限审批可能是「批准」「拒绝」「向上转交」，处理节点显示「确认已处理」；费用报销沿用财务里的「批准 / 向上转交」「驳回」。申请人查看自己的进行中权限申请时可以撤回。所有动作都只在重新加载过的详情中出现，列表不提供快捷批准或跨类型批量处理。

没办成（比如这条申请刚被别人处理了、或者网络断了）会在按钮下方写出原因，按钮恢复后可以再试。

## 注意事项

- 批准的是**一条有有效期的授权**，会进「权限审计」流水，可以随时在那里撤销。
- 申请人的直属上级在「成员与部门 → 汇报上级」里设。没设的话第一级跳过。

## 常见问题

**我批准了，对方说还是没权限？**
到「权限审计」里成员选他、状态选「有效」，找那条来源为「审批」的授权：在 → 权限已经生效，看他是不是开错了资源；不在 → 申请没有真正批完，回「审批中心」看流程停在哪一级。

**申请一直没人理？**
每级 24 小时自动往上升，最终到所有者。急的话在申请详情里看现在在谁手里，直接找他。
