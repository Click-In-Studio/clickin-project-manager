## 这是什么

Backstage 尽量用剧组的话说话，但有几个词在软件里有固定的含义，第一次见到容易含糊。这里一次说清。各功能的细节见对应章节。

## 怎么操作

按需要查即可。

### 项目与人

| 词 | 意思 |
|---|---|
| **项目** | 一部戏。你的所有工作都发生在某个项目里。 |
| **项目所有者** | 建这个项目的人（或被转让的人）。唯一能兑换升级码、转让和删除项目的人。 |
| **管理员** | 能进「配置中心」的成员。所有者一定是管理员，管理员不一定是所有者。 |
| **部门** | 灯光、音响、舞美、服化……成员归属部门，很多权限按部门分配。 |
| **POC** | 部门联络人（Point of Contact）。技术需求先到 POC 手里确认。 |
| **角色** | 两个意思：**职称**（导演、舞监、灯光设计）是人的角色；**剧中角色**（哈姆雷特）在「构作」里管理。界面上写「角色管理」的是前者。 |
| **席位** | 项目的成员人数名额。免费档 10 个、专业档 200 个。 |
| **档位** | 项目的等级：免费档 / 专业档，决定项目里有没有 AI 助手、高级权限配置。 |
| **等级** | 账号的等级：普通 / 创作者，决定能不能自己新建项目。 |

### 创作侧

| 词 | 意思 |
|---|---|
| **剧本** | 一个项目一份剧本，所有人看的是同一份最新版。 |
| **章节 / 段落** | 剧本的层级：章节（幕）下面是段落（场）。软件里统一叫「段落」，避免和「舞台场景」混淆。 |
| **块** | 剧本里的一段内容：一句台词、一条舞台指示、一个歌词段。Cue 和讨论都挂在块上。 |
| **排练记号** | 剧本里的标记点，排练时说「从 12 号记号开始」用的。 |
| **构作** | 从段落层面看整部戏的结构：每场有谁、讲什么、灵感来源。 |
| **Cue** | 部门的执行点：灯光第 37 个变化、音响第 12 条音效。每条 Cue 挂在剧本的某个块上。 |
| **Cue 表** | 一个部门的全部 Cue，有一个全大写简称，比如 LX（灯光）、SQ（音响）。 |

### 制作侧

| 词 | 意思 |
|---|---|
| **事件** | 一次围读、排练、演出、制作会、设计会。有时间、地点、参加的人。 |
| **Call / Call 时间** | 到场时间。日 Call 是明天几点到，周 Call 是本周汇总。 |
| **Call Sheet** | 通告单。一次事件的时间安排、到场时间、地点、联系人，可以发给不用 Backstage 的人看。 |
| **任务 / 技术需求** | 同一样东西的两个叫法：一件要某个部门或某个人去做的事（「这场要一台烟机」），可以挂在某次事件上，也可以不挂。从提出、POC 确认、指派到完成有一条状态线。菜单里叫「任务」，有些地方还写着「技术需求」。 |
| **报告** | 排练或演出结束后的记录：今天做了什么、出了什么问题、各部门备注。 |
| **里程碑 / 阶段** | 里程碑是一个时间点（首演），阶段是一段时间（排练期）。 |
| **知识库** | 项目的文档库：会议纪要、设计说明、参考资料，一棵树组织。 |
| **资产** | 上传的文件：音频、视频、图纸、图片、PDF。资产可以挂到 Cue、事件、任务上。 |
| **挂载** | 把一个资产或文档关联到某个用它的地方（这条 Cue 用这个音频）。挂载不改变它在知识库里的位置。 |
| **物料** | 实物清单：道具、服装、设备。 |

### 通知

| 词 | 意思 |
|---|---|
| **待确认** | 需要你点一下确认的通知，比如你的 Call 时间定了。 |
| **仅告知** | 看一眼就行的通知。 |
| **公告** | 管理员发给全项目的正式通知，可以置顶、可以看谁读了。 |

## 注意事项

- 界面上偶尔还会出现「场景」两个字，意思等同于「段落」。

## 常见问题

**「角色」到底指人还是指戏里的人物？**
看在哪。「配置中心 → 角色管理」是职称；「构作」里的角色是剧中人物。
