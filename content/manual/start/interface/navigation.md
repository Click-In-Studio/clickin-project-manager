## 这是什么

登录后，宽窗口是**顶栏 + 左侧栏 + 正文**；手机是**顶栏 + 单列正文 + 底部标签**，不是把桌面端左侧栏缩小。Backstage 有两层——**项目外**（跨所有项目的「我的」页面）和**项目内**（某一部戏的具体工作），导航内容会跟着切换。

## 怎么操作

### 首页「我的工作」

登录后落在这里。宽窗口和手机横屏可以随时点左上角的圆形标志回来；手机竖屏从项目切换里选「平台首页」。它把今天跟你有关的事汇总在一页：

顶栏的项目切换旁只显示当前页名「我的工作」，正文从项目风险与未确认事项开始。

![宽窗口下的首页「我的工作」](/manual/start/home.png)

- **项目风险与未确认事项**：最近的里程碑倒计时、待你处理的通知数、Cue 风险提示。
- **即将到来 / 本周**：你的 Call 时间，可以切换看今天或整周。
- **我的 Task**：指派给你的任务，按状态排列。
- **待确认**：等你点一下确认的事。
- **报告**：待你完成或未读的演出报告。
- **我的项目**：你参与的项目，点进去就是项目内。

每块右下角都有「查看全部 →」，通往对应的完整页面。

### 左侧栏（项目外）

「项目总览」一组：**我的工作**、**我的项目**、**公告**、**日程**、**任务**、**通知提醒**、**报告**。任务和通知提醒后面的数字是待处理的条数。

进入某个项目后，这一页也叫「我的工作」，但只看这个项目的事，顶部的大卡片会换成管理员置顶的公告。右侧三张指标卡始终同排、同高显示；在平板和较宽的窗口里，它们会减少上下留白，倒计时的数字和「天」保持在同一基线上。点「待处理通知」或「Cue 风险提示」的整张卡会打开对应页面，里程碑名称显示不全时点卡片可展开查看完整内容。

### 左侧栏（项目内）

进入一个项目后，左侧栏变成三组，分别对应剧组工作的两条线：

![宽窗口下的左侧栏：项目总览 / 创作侧 / 制作侧](/manual/start/sidebar-production.png)

- **项目总览**：我的工作、我的通知、审批。
- **创作侧**：**构作**、**剧本**、**Cue**——从文本到各部门的执行设计。
- **制作侧**：**人员**、**计划与日程**、**事件**、**任务**、**报告**、**云文档**、**财务**、**物料**、**资产工作台**——剧组运转的一切。

左侧栏底部有「折叠左侧边栏」按钮，收起后只留图标。项目管理员还会看到「配置中心」，那是管理面板的入口。

同一个模块在宽窗口、折叠侧栏和手机菜单里使用相同的线框图标：房子表示「我的工作」，叠放卡片表示项目，喇叭表示通知，印章表示审批。人员沿用「个人信息」的图标；配置中心各项也有对应图形。折叠后把鼠标停在图标上可以查看名称，手机菜单保留名称和说明。

每一项在本手册里都有对应章节：「创作」「制作」「管理项目」。

### 顶栏

从左到右：

- **圆形标志**：项目外是「BS」，项目内是项目名的第一个字。点它回首页。手机竖屏不显示这一项，把位置留给项目切换和当前页面的工具；手机横屏与宽窗口仍会显示。
- **项目切换**：项目外写着「选择项目」，项目内显示当前项目名和你在里面的职称。窄窗口下按钮和下拉会一起收紧，但项目名、职称和入口不变。点开后最上面「平台首页」回到项目外，下面列着你的所有项目。点了某一项之后，按钮会立刻换成目标的名字并转圈，左侧栏也同时离开原来的高亮，新页面打开后转圈消失；等待期间不用再点一次。按住 ⌘ / Ctrl 点某个项目，会在新标签页里打开它。

  ![宽窗口下的项目切换下拉](/manual/start/project-switcher.png)
- **当前模块与顶部菜单**：进入项目后，项目切换已经持续显示当前项目，因此旁边只保留带边框的当前模块名，避免重复。项目总览使用中性灰、创作侧使用青蓝、制作侧使用暖橙，与左侧栏的三组颜色一致；即使宽窗口收起左侧栏，也能从这里确认自己在哪一类、哪个模块。事件、任务、报告、文档、资产等详情页还会在正文保留具体名称。
- **项目外的页名**：我的工作、我的项目、公告与风险提醒、日程、我的任务、通知提醒、报告，以及个人中心各个设置页和登录后的每日 Call Sheet，顶栏都只显示当前页名，不再另放「平台级」「Platform · 日程」这类分类小字，正文也不重复显示大标题。切换日程视图或个人中心页签时，顶栏名称会跟着变化；日期范围、说明和筛选仍留在正文。对外分享的每日 Call Sheet 保留独立页头。
- **我的项目操作**：「调整顺序」和可用的「新建项目」位于顶栏。窄窗口放不下时会收进「更多」，项目搜索、状态与角色筛选仍在正文。
- **页面操作**：新建、上传、申请、管理预算等页面操作会出现在当前模块右侧。窗口变窄时，搜索先收成图标，次要操作再进入「更多」，主操作会先缩短、最后也进入「更多」；审批、财务和资产工作台的主操作与搜索或「更多」之间会保留间距，当前模块和各个入口不会挤出屏幕。
- **搜索框**：搜日程、人员、任务、剧本章节和段落。输入一个日期（例如「9月20日」）直接列出那天的日程。
- **AI 助手**：圆形的「AI」按钮，点开右侧对话框。项目外一直有；项目内只在专业档项目里出现。
- **头像**：个人信息、账号安全中心、功能与设置、本页帮助、使用手册、更新日志、报告问题、配置中心（管理员）、退出登录。发了新版本还没看过时，头像上有红点，「更新日志」旁标着「新」；点开看一眼就消。

  ![宽窗口下的头像菜单](/manual/start/avatar-menu.png)

### 手机 / 窄窗口

左侧栏收起，改为底部四个标签：项目外是 **今日 / 项目 / 概览 / 我**，项目内是 **概览 / 创作 / 制作 / 我**。项目内点「概览」可以打开**我的工作、我的通知、审批**；点「创作」「制作」展开对应的一组菜单。

点「我」可以打开个人信息、账号安全中心、功能与设置、本页帮助、使用手册、更新日志、报告问题，以及管理员可见的配置中心。每个入口左侧都有含义对应的线框图标，窄屏下仍以文字名称为准。

四个标签中间的圆形 **AI** 按钮打开全屏对话；点右上角的「✕」就回到刚才的内容和位置。免费档项目里不出现这个按钮，四个标签仍然等宽排列；离开项目回到平台页面后，可以继续使用个人 AI 助手。

手机浏览器的地址栏展开、收起或切换横竖屏时，顶栏、底部标签和抽屉会自动留在当前可操作区域内。

开始输入文字后，底部标签会暂时收起，把空间让给输入框和当前操作；收起键盘后会自动恢复。表单或抽屉内容较长时，可以在其中上下滚动，提交按钮不会落到键盘后面。

![手机宽度下的项目首页与底部标签](/manual/start/mobile-tabs.png)

> [!📱]
> 项目内所有页面在窄窗口下都会保留当前模块名。操作较多时点顶栏的「更多」；剧本、Cue 的页面内菜单继续按各自章节所述收缩。

## 注意事项

- 换页时正文会先出现一行「正在打开「××」…」和几条灰色占位，几秒内换成真正的页面；剧本页打开时也是同一个画面，不用重复点。
- 有些菜单项你可能看不到。两种原因：项目档位没开这个功能（比如免费档没有 AI 助手），或者管理员没给你这项权限。前者找项目所有者升级，后者找管理员分配。
- 灰色的按钮是「这里有这个功能，但你现在不能用」。宽窗口把鼠标停上去会显示原因；手机没有悬停，页面若没有把原因写在按钮附近，需换到宽窗口查看。

## 常见问题

**左侧栏怎么没了？**
窗口太窄时左侧栏自动收进底部标签；宽窗口下可能是被折叠了，点左下角的展开按钮。

**怎么切换到另一个项目？**
顶栏的项目名旁边有下拉箭头，点开选另一个；要回首页就选「平台首页」。宽窗口和手机横屏也可以点左上角标志回首页，再从「我的项目」里选。

**更新期间暂时打不开怎么办？**
涉及数据调整的系统更新会短暂停止访问，避免切换期间提交的操作显示成功、实际却没有保存。稍等片刻后刷新页面即可；仍打不开时再通过「报告问题」反馈。
