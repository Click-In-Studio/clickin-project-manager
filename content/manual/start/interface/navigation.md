## 这是什么

登录后你会看到三块：**顶栏**、**左侧栏**和中间的**正文**。Backstage 有两层——**项目外**（跨所有项目的「我的」页面）和**项目内**（某一部戏的具体工作），左侧栏的内容会跟着切换。

## 怎么操作

### 首页「我的工作」

登录后落在这里，也可以随时点左上角的圆形标志回来。它把今天跟你有关的事汇总在一页：

- **项目风险与未确认事项**：最近的里程碑倒计时、待你处理的通知数、Cue 风险提示。
- **即将到来 / 本周**：你的 Call 时间，可以切换看今天或整周。
- **我的 Task**：指派给你的任务，按状态排列。
- **待确认**：等你点一下确认的事。
- **报告**：待你完成或未读的演出报告。
- **我的项目**：你参与的项目，点进去就是项目内。

每块右下角都有「查看全部 →」，通往对应的完整页面。

### 左侧栏（项目外）

「项目总览」一组：**我的工作**、**我的项目**、**公告**、**日程**、**任务**、**通知提醒**、**报告**。任务和通知提醒后面的数字是待处理的条数。

### 左侧栏（项目内）

进入一个项目后，左侧栏变成三组，分别对应剧组工作的两条线：

- **项目总览**：我的工作、我的通知、资源申请。
- **创作侧**：**构作**、**剧本**、**Cue**——从文本到各部门的执行设计。
- **制作侧**：**人员**、**计划与日程**、**事件**、**任务**、**报告**、**知识库**、**财务**、**物料**、**资产工作台**——剧组运转的一切。

左侧栏底部有「折叠左侧边栏」按钮，收起后只留图标。项目管理员还会看到「配置中心」，那是管理面板的入口。

每一项在本手册里都有对应章节：「创作」「制作」「管理项目」。

### 顶栏

从左到右：

- **圆形标志**：项目外是「BS」，项目内是项目名的第一个字。点它回首页。
- **项目名 / ← 返回**：项目内显示当前项目，点「← 返回」回到项目外。
- **顶部菜单**：在剧本、构作、Cue 页面出现，放的是这些页面各自的开关和视图切换。
- **搜索框**：搜日程、人员、任务、剧本章节和段落。输入一个日期（例如「9月20日」）直接列出那天的日程。
- **AI 助手**：专业档项目里出现，点开右侧对话框。
- **头像**：个人信息、账号安全中心、功能与设置、使用手册、配置中心（管理员）、退出登录。

### 手机 / 窄窗口

左侧栏收起，改为底部四个标签：项目外是 **今日 / 项目 / 概览 / 我**，项目内是 **今日 / 创作 / 制作 / 我**。点「创作」「制作」展开对应的一组菜单。

> [!📱]
> 剧本、Cue 这类操作密集的页面在窄窗口下会把操作收进底部菜单，具体见各自章节。

## 注意事项

- 有些菜单项你可能看不到。两种原因：项目档位没开这个功能（比如免费档没有 AI 助手），或者管理员没给你这项权限。前者找项目所有者升级，后者找管理员分配。
- 灰色的按钮是「这里有这个功能，但你现在不能用」，把鼠标停上去会显示原因。

## 常见问题

**左侧栏怎么没了？**
窗口太窄时左侧栏自动收进底部标签；宽窗口下可能是被折叠了，点左下角的展开按钮。

**怎么切换到另一个项目？**
点左上角标志回首页，在「我的项目」里选；或者顶栏点「← 返回」再选。
