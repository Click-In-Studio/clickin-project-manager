## 这是什么

一个项目一份剧本，所有人打开看到的都是同一份最新版。宽窗口从左侧栏「创作 → 剧本」进入；手机点底部「创作 → 剧本」。

页面三栏：左边**目录**（章节 / 段落），中间**正文**，右边**构作详情**（当前段落的简介、行动线、音乐、舞台呈现）。顶栏右侧多出一排剧本专用菜单：**剧本 / 章节 / 角色 / 编辑 / 显示 / 导出**，旁边的小头像是此刻在线的人，「可编辑」或「只读」标出你对这份剧本的权限。

![宽窗口下的剧本页：目录、正文和构作详情同时展开](/manual/creation/script.png)

> [!📱]
> 手机上改为单列：目录排在正文上方，构作详情不占右栏，剧本工具收进顶部「更多」。

![手机上的剧本：目录在正文上方，台词单列排列](/manual/creation/script-mobile.png)

正文由一个个**块**组成：一句台词、一条舞台提示、一段歌词、一个标记（章节 / 段落 / 排练记号）。每块左边有行号，右边有它所在的段落编号。

## 怎么操作

### 定位

- **目录**：宽窗口在左侧，手机在正文上方；点章节或段落名直接跳过去。
- **跳转**：宽窗口打开「编辑」菜单，手机打开「更多」，再选「跳转到行…」「跳转到页…」。页是按当前页面类型分页后的页码，和打印稿一致，排练时说「第 12 页」大家能对上。
- **搜索**：宽窗口用「编辑 → 搜索」或 ⌘/Ctrl+F；手机点顶部搜索图标，在剧本内查找台词。
- **顶栏搜索框**也能搜到章节和段落，跨页面用。

长剧本会先打开当前位置附近的正文，并在你阅读或编辑时继续在后台加载其余部分。滚动、搜索、目录和行页跳转永远优先；已经后台加载过的位置可以直接到达。网络较慢时，仍未到达的正文会保持为剧本行形状的浅色占位，跳转会等目标位置准备好再定位，不会先把当前画面切走。

### 显示开关（「显示」菜单）

| 开关 | 作用 |
|---|---|
| 分页线 | 显示每页的分界，和打印稿对齐 |
| 行号 | 每块左边的编号 |
| Block 标签 | 显示块上打的标签（见「编辑」页） |
| 逐行章节 | 每行右侧都标出所属段落编号 |
| 构作详情 | 右侧那一栏的开关；窗口太窄时自动收起 |
| 紧凑排版 | 缩小行距和留白，一屏看更多 |
| 排练模式 | 见「讨论与协作」页 |

这些开关只影响你自己的屏幕。

### 「剧本」菜单里的全局设置

这几项是**整个项目共用**的，改了所有人都变：

- **显示开场**：演出正式开始前的那段（前厅广播、序曲提示）是否显示。开场里已经有段落或排练记号时它会被锁定在显示状态。
- **使用排练记号**：项目是否启用排练记号。剧本里已经有排练记号时关不掉。
- **段内舞台提示**：台词里夹的舞台提示用（）还是【】。
- **页面类型**：A4 / Letter / A3 横排双排 / Tablet 横排双排。决定分页和打印版式，需要剧本排版权限才能改。
- **标签设置…**：定义可以打在块上的标签（见「编辑」页）。
- **关于 · 快捷键**：快捷键一览。

### 构作详情

右栏显示当前所在段落的构作字段，可以直接在这里改（有对应权限的话）。它和「构作视图」是同一份数据。段落标记的菜单里也有「查看构作详情」，弹窗查看和编辑。

## 注意事项

- 「只读」不代表什么都不能做——评论和附件通常对只读成员也开放，看你被授的权限。
- 页码依赖页面类型。有人把项目的页面类型从 A4 改成 A3，所有人的页码都会变，改之前在群里说一声。
- 编辑时如果网络中断，页面会提示「等待网络，修改尚未同步」。不要关闭页面；连接恢复后会自动继续保存。

## 常见问题

**右边的构作详情不见了？**
宽窗口可以在「显示」菜单里把「构作详情」打开。手机不显示常驻右栏；点段落左侧的 **⋮** 再选「查看构作详情」。

**手机上怎么看？**
目录在正文上方，正文单列显示；顶部「更多」收着搜索、跳转、显示设置等工具。查看某段构作详情时，用该段左侧的 **⋮**。
