## 这是什么

剧组通常已经有一份剧本，在 Word 或飞书文档里。导入功能把它变成 Backstage 里一块一块的台词，省掉手动录入。

导入走**飞书表格**：先把剧本整理成表格（一行一句，有角色列、台词列、场次列），再把表格链接贴进来。入口在「配置中心 → 数据迁移」，有两个：

- **导入剧本**：从飞书表格导入台词、角色、场景号。
- **导入构作**：从飞书表格导入场次、梗概、时长。

> [!⚠️ bg=#f5edda]
> **导入会覆盖项目里已有的构作、剧本内容和全部 Cue。** 它是给项目开头用的，不是更新工具。剧本已经在 Backstage 里改过、Cue 已经挂上去了，就不要再导——那些都会没。

## 怎么操作

1. 「配置中心 → 数据迁移」→「导入数据」。
2. 页面顶部是步骤条：导入构作 → 构作配置 → 导入剧本 → 剧本配置 → 类型映射 → 格式映射 → 角色配置 → 聚合角色 → Cue 映射 → 确认 → 完成。
3. 第一步贴构作表格的链接，点「加载」；没有构作表可以「跳过」，之后按剧本里的章节分割自动生成。
4. 之后每一步是告诉系统表格里哪一列是什么：哪列是角色、哪列是台词、哪些值代表舞台提示、哪些角色要合并成群像、哪列是 Cue。
5. 「确认」页会列出即将导入的数量，看清楚再点完成。

## 注意事项

- 链接支持飞书电子表格地址和 wiki 地址两种。点「加载」提示加载失败，多半是表格没有对外开放读取，先在飞书里把表格权限放开再试。
- 导入后先在剧本页翻一遍：角色是否对应正确、舞台提示有没有被当成台词。这些在剧本里改比重导快。
- 构作里有、剧本表格里却一句台词都没有的场次，导入后会带一行空白台词，好让你能直接点进去写；剧本表格里没有任何章节时会自动加一个开场章放在最前。

## 常见问题

**我的剧本是 Word 文件，没有表格怎么办？**
专业档项目的 AI 助手可以直接读 Word / PDF 帮你整理，见「AI 助手」章节。免费档先在飞书里整理成表格。
