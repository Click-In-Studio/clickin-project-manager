## 这是什么

剧本是**多人实时协作**的：你打字，别人屏幕上立刻出现；顶栏的小头像就是此刻在线的人。没有「保存」按钮，也没有版本要切——永远只有一份最新的。

## 怎么操作

### 写台词

1. 点进任意一块，光标落下就能改。
2. 按 **Enter** 在这块后面新建一块；**⇧Enter** 是块内换行（同一句里断行）。
3. 新块默认是台词。点块左上的角色名给它指定说话的人——下拉里是「角色」表里的全部人物，找不到就在剧本顶部菜单「角色」里现加一个。
4. 一块开头按 **Backspace**，会把它并进上一块（类型和角色相同时）。

### 块的类型

| 类型 | 是什么 | 怎么变 |
|---|---|---|
| 台词 | 某个角色说的话 | 默认 |
| 舞台提示 | 独立一段的动作、灯光、场景描述 | 块菜单「转为舞台提示」，或 ⌘/Ctrl+I |
| 段内括注 | 夹在台词里的短提示，（停顿） | 选中台词里的文字按 ⌘/Ctrl+I |
| 歌词 | 唱段，排版不同 | 块菜单「转为歌词」，或 ⌘/Ctrl+Shift+L |
| 演员提示 | 挂在一句台词下面的小字（语气、动作） | 块菜单「添加演员提示 / 补充舞台提示」 |

鼠标停在一块上，右上角出现快捷按钮：**歌词 / 舞台 / 附件 / 评论**，再往左的小三角是完整菜单（「更多操作」）。

台词里选中文字可以**粗体**（⌘/Ctrl+B）、**下划线**（⌘/Ctrl+U）。

### 章节、段落、排练记号

这三种都是**标记**，插在剧本流里当分隔线。

- 在块的菜单里选「在块前添加」→「添加新章」「添加新段」「添加新排练记号」，标记就插在这块前面。
- 点标记可以改名；标记的菜单里有「转为章节 / 转为段落」互转，「查看构作详情」，「删除此标记」。
- 标记也能拖：拖的只是这条分隔线本身，台词不跟着走。要整段搬家，先用连续多选把标记和它下面的台词一起选中，再拖。

> [!💡]
> 排练记号是给排练用的定位点（「从 12 号记号开始」）。要先在「剧本」菜单里打开「使用排练记号」；一旦剧本里有了记号，这个开关就关不掉了。

### 挪动与多选

- 拖块左侧的把手到目标位置松手。
- 点块左侧的把手选中这一块；按住 ⇧ 再点另一块的把手，中间的全部选中（连续多选）；选中后可以整批拖动、删除、清除空白、转换类型。一次选超过 500 行会提示可能卡顿。
- 「剧本」菜单 →「清除空白内容」一键删掉所有空块。

### 标签

给块打标签是为了统计和筛选：这句台词的情绪、这段的排练完成度、灯光需求……

1. 「剧本」菜单 →「标签设置…」定义标签组：每组一个名字，类型是**单选**（几个选项里挑一个）或**数值**（有最小、最大、步长、默认值）。
2. 块菜单里打标签。⌘/Ctrl+Shift+C 复制当前块的标签，⌘/Ctrl+Shift+V 贴到别的块。
3. 「显示」→「Block 标签」控制是否显示。

### 附件

块菜单「附件」可以把资产库里的文件挂到这一句上——参考录音、一张图。附件在右侧面板里看，「上一条 / 下一条」在有附件的块之间翻。

### 快捷键

Mac 用 ⌘，Windows 用 Ctrl，效果一样。菜单里显示的是 ⌘ 写法。

| Mac | Windows | 作用 |
|---|---|---|
| ⌘Z / ⌘⇧Z | Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 |
| ⌘F | Ctrl+F | 搜索 |
| ⌘B / ⌘U | Ctrl+B / Ctrl+U | 粗体 / 下划线 |
| ⌘I | Ctrl+I | 切换舞台提示 / 段内括注 |
| Enter / ⇧Enter | Enter / Shift+Enter | 新建块 / 块内换行 |
| Backspace（行首） | Backspace（行首） | 并入上一块 |
| ⌘⇧L | Ctrl+Shift+L | 切换歌词模式 |
| ⌘⇧C / ⌘⇧V | Ctrl+Shift+C / Ctrl+Shift+V | 复制 / 粘贴标签 |

> [!📱]
> 窄窗口下块的菜单收进底部：点一块，底部弹出操作条。多选、删除确认的规则和宽窗口一样。

## 注意事项

- 删除章节或段落标记不会删台词，台词并入前一段。删除**块**才是真的删内容。
- 有人在剧本里加了 Cue，你改动那附近的台词时 Cue 会跟着走；把整块删掉，挂在上面的 Cue 会变成「失效」，Cue 表那边会亮红。删大段之前和技术部门打个招呼。
- 撤销只对你自己这一会儿的操作有效，别人的改动你撤不回。

## 常见问题

**能不能回到昨天的版本？**
没有版本切换。剧本只有一份最新的，改错了当场 ⌘/Ctrl+Z。

**为什么我改不了台词，只能加评论？**
两种可能：你只有查看权限（右上角是「只读」）；或者你自己开着「排练模式」，见「讨论与协作」页。
