## 这是什么

「构作」是从**段落**（场）这一层看整部戏。剧本是一句一句的台词，构作是一场一场的骨架：这场叫什么、讲什么、人物在追求什么、用哪首曲子、大概多长。

宽窗口从左侧栏「创作 → 构作」进入；手机点底部「创作 → 构作」。顶部有三个去处：**构作视图**、**角色**、**灵感文档**。本页讲第一个。

顶部工具会按窗口实际能容纳的空间逐项收纳。「构作视图 / 角色 / 灵感文档」切换最优先保留，其次是「表格 / 列表」、只读 / 编辑模式、「列设置」和保存视图。标签保持完整。

点「更多」会在第一栏下方展开第二栏，正文随之向下让出空间。第二栏里的每个按钮都能直接打开自己的菜单。编辑、选文字、点击正文和切换模式不会收起第二栏；再点「更多」、切换页面或工具全部回到第一栏时收起。极窄窗口下第二栏可以左右滑动。

每个段落有这些字段：

| 字段 | 写什么 |
|---|---|
| 编号 / 名称 | 自动编号（0-1、0-2……），名称自己起 |
| 简介 | 这场发生了什么 |
| 行动线 | 人物在这场里要达成什么 |
| 音乐 | 这场用的曲目 |
| 舞台呈现 | 调度、视觉上的想法 |
| 预期时长 | 估计演多久，章节一级会自动汇总 |
| 排练记号 | 这场里有哪些排练记号（在剧本里加，这里只显示） |
| 附件 | 挂在这场上的文件 |

这些字段在剧本页右侧的「构作详情」栏里也能看和改，两边是同一份数据。

## 怎么操作

### 只读 / 编辑模式

用顶部的模式下拉在「只读」和「编辑」之间切换；按钮收纳后，展开「更多」即可直接使用。有修改权限时默认进入「编辑」；切到「只读」后，仍可查看、展开、筛选和切换列表 / 表格，但页面不会显示改字段、增删章节、调整顺序或关联附件等入口。

构作视图和角色页共用这一选择，当前浏览器会按项目记住，刷新后仍沿用。没有对应修改权限时只能使用「只读」，模式不会替你增加或取消任何权限。

切到「只读」时，页面会先保存正在编辑的字段。保存失败或新增表单里还有没提交的内容时，页面会留在「编辑」并保留输入，按提示保存或取消后再切换。

### 列表 / 表格两种看法

「表格 / 列表」优先保留在第一栏，空间放不下时整组进入第二栏；两项名称始终显示，当前选中的一项会高亮。首次进入默认打开**表格**，把所有字段铺开，适合总览和批量填写——单击格子就能改，内容多的格子会自动变高。手机上的表格保留全部列，需要左右滑动；日常阅读和单条修改更适合切到**列表**。列表以紧凑行展示章节与段落，行间的「添加章节或段落」可就地插入。点名称可以直接改名，点左侧箭头展开全部字段。

你主动切换后，当前浏览器会分别记住构作页和角色页的选择；换到另一台设备或另一个浏览器时，从默认表格重新开始。

> [!📱] 列表展开的章节或段落详情在手机上逐项排列：预期时长、简介、行动线、音乐、舞台呈现。宽窗口下并排显示。各项内容字号与预期时长一致；多行输入框起始显示三行，可上下滚动，也可拖动右下角调整高度。修改后离开输入框即可保存，只读模式下长内容会自动换行。

段落的「预期时长」可输入「1:30」「1分30秒」或「90秒」。点「保存」、按 Enter 或点击输入框外保存，按 Escape 或点「取消」放弃修改。保存过程中输入和按钮会暂时停用；保存失败时会保留输入并显示提示，可再次保存。这也适用于剧本页的构作详情。

### 自定义表格视图

宽窗口的表格右上角有「列设置」；手机在顶部「更多 → 列设置」。选择显示哪些列、什么顺序；每列还有「冻结」，冻结的列会排到最前面，横向滚动时留在原地不动，并会跟随章节底色和整行高亮（表头本来就固定，不用设）。调好后可以「保存到当前视图」，或者存成一个新视图（起个名字，比如「音乐总表」）；视图是全项目共用的，可以「设为默认」让所有人打开就是这一版。

### 增删章节和段落

- 表格上方「新增章节」可以在末尾加章，空表格也能直接开始。每行左侧「⋯」打开行操作：在段落前后插入段落、在章首或章末加段落、在当前位置后加章，填写名称后点「添加」。行操作固定在左侧，左右滑动表格后仍可找到。
- 表格行操作中的「删除」先询问确认，再按当前内容给出结果。包含构作详情的章节或段落暂时需要先清空详情；章节下都是空段落时，还会询问是否保留下属段落。取消不会删除。
- 列表底部「添加章节或段落」：填名称，选加章还是加段。还没有任何章节时，列表中间会直接给出这个入口。
- 行末菜单：「转换类型」把一段升成一章、或把一章降成一段；「删除」。
- 也可以在剧本页里操作（剧本顶部菜单「章节」），两边同步。

> [!💡]
> 删除章节或段落不会删掉里面的台词——只是去掉这个标记，台词并入前一段。真正的删台词在剧本里做。

### 拖动调整顺序

表格左侧「⠿」是拖柄，按住拖到同级行的上沿或下沿，看到蓝色落点线后松手。手机或不方便拖动时，打开该行「⋯」，使用「上移 / 下移」。没有相应操作权限、已经到达边界或属于固定开场章节时，行操作会说明原因。保存失败会显示提示；可点「重试同步」确认最新顺序。

结构操作失败后，表格会重新读取当前章节和段落。如果同步也失败，新增、删除和排序会暂停；点击「重试同步」，同步成功后再继续操作。

编辑模式且有顺序调整权限时，列表编号左边会显示六点排序按钮。六点始终可见，鼠标移到按钮上时出现外框；用键盘选中时也会显示焦点。宽窗口可按住按钮拖到目标行的上沿或下沿，蓝线表示落点；松手后保存。手机或不方便拖动时，点击排序按钮，再点「上移」或「下移」；用完可点「收起排序」。段落只能在**本章内**上下移动，拖到别的章上不会有反应；章节拖动时整章连同下面的段落和台词一起搬。顺序改的是剧本本身，剧本页里的台词顺序会跟着变。

开场那一章（编号 0）固定在最前面：它自己没有排序按钮，别的章也放不到它前面。取消拖动或放回原位不会保存。保存失败时会提示并重新读取当前顺序；若网络中断导致读取也失败，点「重试读取顺序」或刷新后再操作。若提示登录已失效，重新登录后再调整顺序。

## 注意事项

- 章节、段落、排练记号在软件里统称「标记」。它们不是独立的容器，而是插在剧本流里的分隔线，所以一个段落的内容 = 它的标记到下一个标记之间的所有块。
- 字段是分开授权的。你可能能改「简介」却改不了「音乐」，那是管理员按部门开的权限，不是故障。
