## 这是什么

「构作」是从**段落**（场）这一层看整部戏。剧本是一句一句的台词，构作是一场一场的骨架：这场叫什么、讲什么、人物在追求什么、用哪首曲子、大概多长。

宽窗口从左侧栏「创作 → 构作」进入；手机点底部「创作 → 构作」。顶部有三个去处：**构作视图**、**角色**、**灵感文档**。本页讲第一个。

窗口较窄时，三个页签会收进顶部的「构作视图」下拉。选择一项即可前往对应页面；点下拉外的任意位置，菜单会立即收起。

每个段落有这些字段：

| 字段 | 写什么 |
|---|---|
| 编号 / 名称 | 自动编号（0-1、0-2……），名称自己起 |
| 简介 | 这场发生了什么 |
| 行动线 | 人物在这场里要达成什么 |
| 音乐 | 这场用的曲目 |
| 舞台呈现 | 调度、视觉上的想法 |
| 预期时长 | 估计演多久，章节一级会自动汇总 |
| 排练记号 | 这场里有哪些排练记号（在剧本里加，这里只显示） |
| 附件 | 挂在这场上的文件 |

这些字段在剧本页右侧的「构作详情」栏里也能看和改，两边是同一份数据。

## 怎么操作

### 列表 / 表格两种看法

宽窗口的「表格 / 列表」在顶部直接显示；手机从顶部「更多」里切换。首次进入默认打开**表格**，把所有字段铺开，适合总览和批量填写——单击格子就能改，内容多的格子会自动变高。手机上的表格保留全部列，需要左右滑动；日常阅读和单条修改更适合切到**列表**。列表一行一个段落，点名称可以直接改名，点左侧箭头展开全部字段。

你主动切换后，当前浏览器会分别记住构作页和角色页的选择；换到另一台设备或另一个浏览器时，从默认表格重新开始。

### 自定义表格视图

宽窗口的表格右上角有「列设置」；手机在顶部「更多 → 列设置」。选择显示哪些列、什么顺序；每列还有「冻结」，冻结的列会排到最前面，横向滚动时留在原地不动（表头本来就固定，不用设）。调好后可以「保存到当前视图」，或者存成一个新视图（起个名字，比如「音乐总表」）；视图是全项目共用的，可以「设为默认」让所有人打开就是这一版。

### 增删章节和段落

- 列表底部「添加章节或段落」：填名称，选加章还是加段。还没有任何章节时，列表中间会直接给出这个入口。
- 行末菜单：「转换类型」把一段升成一章、或把一章降成一段；「删除」。
- 也可以在剧本页里操作（剧本顶部菜单「章节」），两边同步。

> [!💡]
> 删除章节或段落不会删掉里面的台词——只是去掉这个标记，台词并入前一段。真正的删台词在剧本里做。

### 拖动调整顺序

列表视图里鼠标移到一行上，编号左边会出现「⋮⋮」拖柄，按住拖到目标行的上沿或下沿松手即可。手机上没有拖柄，调整章节和段落顺序需要换到宽窗口。段落只能在**本章内**上下移动，拖到别的章上不会有反应；章节拖动时整章连同下面的段落和台词一起搬。顺序改的是剧本本身，剧本页里的台词顺序会跟着变。

开场那一章（编号 0）固定在最前面：它自己没有拖柄，别的章也放不到它前面。

## 注意事项

- 章节、段落、排练记号在软件里统称「标记」。它们不是独立的容器，而是插在剧本流里的分隔线，所以一个段落的内容 = 它的标记到下一个标记之间的所有块。
- 字段是分开授权的。你可能能改「简介」却改不了「音乐」，那是管理员按部门开的权限，不是故障。

## 常见问题

**段落能不能拖到另一章里？**
