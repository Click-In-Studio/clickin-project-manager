## 这是什么

**资产**是项目里的文件：灯位图、音效素材、排练录像、乐谱、QLab 工程、参考图。「制作 → 资产工作台」是文件的总清单；每个文件同时在知识库的树里有一个位置（默认在「资产」目录下），从那边也能打开。

![资产工作台](/manual/production/assets.png)

页面顶部显示存储占用（含历史版本）；列表分「对全员列出」和其他；可以按「全部 / 我的上传」筛，搜文件名或类型。每行有类型、大小、所在位置、「下载」「分享」。

## 怎么操作

### 上传

1. 「＋ 上传新 Asset」。
2. 两种来源：**上传文件**（点击、拖拽或粘贴，支持所有格式，图片自动生成缩略图）或**飞书链接**（贴一个飞书 Wiki 节点链接，资产工作台只记一个入口，文件仍在飞书）。
3. **位置**：默认「资产」目录，「更改」可以放进知识库的任何目录。
4. **显示名称**（留空用文件名）、**类型**：图纸 / 平面图 / Demo / 排练视频 / Reference / 素材 / 片段 / QLab / 乐谱 / 录音。
5. 「确认上传」。大文件分片上传，网络不稳会自动降低分片大小，页面提示「直传受阻，已切换至服务器中转」时不用管，等它传完。

一次只能传一个文件。

### 新版本

同一个文件改了（图纸 v3），不要另传一个——打开它，「上传新版本」。旧版本保留，所有挂着它的地方（Cue、事件、剧本块）自动指向新版本。

### 编辑

「编辑 Asset」改显示名称、类型；「对全员列出」开关决定它在全员的知识库树里可见（列出 ≠ 能打开，内容访问仍按权限）。

### 挂载点

文件详情里的「挂载点」列出它被用在哪：哪条 Cue、哪场事件、剧本哪一块。「+ 添加」可以从这里主动挂到某处。删除文件时所有挂载点一并消失，页面会确认。

## 注意事项

- 删除只有上传者和管理员能做，不可恢复。
- 存储占用算历史版本。用「新版本」比另传一份省空间，也不会让别人挂错文件。

## 常见问题

**上传的文件同事在知识库里看不到？**
默认只有上传者和被分享的人看得到。要么开「对全员列出」，要么在知识库里把它分享给部门或个人。
