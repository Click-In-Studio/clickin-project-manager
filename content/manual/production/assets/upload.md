## 这是什么

**资产**是项目里的文件：灯位图、音效素材、排练录像、乐谱、QLab 工程、参考图。「制作 → 资产工作台」是文件的总清单；每个文件同时在云文档的树里有一个位置（默认在「资产」目录下），从那边也能打开。

![宽窗口下的资产工作台](/manual/production/assets.png)

页面顶部显示存储占用（含历史版本）；列表分「对全员列出」和其他；可以按「全部 / 我的上传」筛，搜文件名或类型。每行有类型、大小、所在位置、「下载」「分享」。下载会保留上传时的原文件名，包括中文名称。

## 怎么操作

### 上传

1. 宽窗口点顶部「＋ 上传新 Asset」；手机从底部「制作 → 资产工作台」进入，顶栏空间足够时显示「＋」，更窄时收进「更多 → 上传新 Asset」。
2. 两种来源：**上传文件**（电脑可点击、拖拽或粘贴；手机点选文件，支持所有格式，图片自动生成缩略图）或**飞书链接**（贴一个飞书 Wiki 节点链接，资产工作台只记一个入口，文件仍在飞书）。
3. **位置**：默认「资产」目录，「更改」可以放进云文档的任何目录。
4. **显示名称**（留空用文件名）、**类型**：图纸 / 平面图 / Demo / 排练视频 / Reference / 素材 / 片段 / QLab / 乐谱 / 录音。
5. 「确认上传」。上传任务会收进页面右下角，可以继续去项目里的其他页面；大文件会分片上传，网络不稳时自动切换服务器中转。

一次只能传一个文件。

上传失败的任务会保留在右下角，可重试或移除；离开本站或刷新页面会中断仍在进行的任务，浏览器会先提醒。取消分片上传时，已经传出的分片也会一并清理。

### 新版本

同一个文件改了（图纸 v3），不要另传一个——打开它，「上传新版本」。旧版本保留，所有挂着它的地方（Cue、事件、剧本块）自动指向新版本。

作为报销凭证等业务依据上传的文件不提供「新版本」：传错时请重新上传一份，再从对应业务入口关联正确文件。

### 编辑

「编辑 Asset」改显示名称、类型；「对全员列出」开关决定它在全员的云文档里可见（列出 ≠ 能打开，内容访问仍按权限）。

### 挂载点

文件详情里的「挂载点」列出它被用在哪：哪条 Cue、哪场事件、剧本哪一块。「+ 添加」可以从这里主动挂到某处。删除文件时所有挂载点一并消失，页面会确认。

在 Cue、事件等位置选择「上传资产」后，确认上传就同时确认了挂载，不需要上传完再选一次。附件区先显示「上传中」；文件传完后自动挂载。若文件已经传好但挂载失败，点「重试」只会重试挂载，不会重复上传文件。

## 注意事项

- 在云文档里，文件的「重命名」「删除」分别按你获得的权限显示为可用或灰色；宽窗口把鼠标停在灰色选项上可以查看原因。手机目前的「云文档」抽屉不提供这两项行级管理操作，请换到宽窗口处理。上传者的权限也可能被调整。删除不可恢复。
- 存储占用算历史版本。用「新版本」比另传一份省空间，也不会让别人挂错文件。

## 常见问题

**上传的文件同事在云文档里看不到？**
默认只有上传者和被分享的人看得到。要么开「对全员列出」，要么在云文档里把它分享给部门或个人。
