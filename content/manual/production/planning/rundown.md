## 这是什么

「计划与日程 → 执行日程」是舞监手里那张现场表（Rundown）：横向是**人员组**（乐队、演员、灯光、道具……或某几个具体的人），纵向是时间，15 分钟一格，每个格子里的**事项块**写着这一组这一刻在干什么、在哪。

它属于某一个事件——先在顶部「日期 / 事件」下拉里选一天的哪场排练。事件的流程项（见「事件详情」）会作为骨架出现在这里。

## 怎么操作

### 看

- **列视图 / 全员视图**：按人员组分列，或者所有人合成一列看总流程。
- **关注成员**：只看某些人的列，比如只看自己。
- 事项块颜色和状态（待处理 / 待确认 / 进行中 / 完成）一目了然。

### 编辑

1. 右上角「编辑执行表」。
2. **人员组**：「＋ 新增地点列」加一列；双击列头「编辑人员组」，可以选部门、选角色（按角色批量选人）、选个人；「钉住此列」让它横向滚动时留在左边；长按拖动调整列顺序。
3. **事项块**：点空白处新建，填标题、类型（集合 / 执行 / 休息 / 备注 / 任务 / 自定义）、开始结束、地点、状态、说明、颜色，选它显示在哪几个人员组。拖动整块换组或换时间；拖上下边缘改长短。
4. 「完成编辑」退出。

## 注意事项

- 两个人同时改同一张表，后保存的那位会被提示「版面已被其他成员更新，请刷新页面后再编辑」——刷新，看一眼对方改了什么，再改自己的。
- 事项块可以绑定任务，任务的状态会同步显示。

## 常见问题

**执行表和事件里的「事件流程」是什么关系？**
事件流程是那天的大纲（几点到几点做什么），执行表是把大纲拆到每个组、每一刻。流程项会自动出现在执行表里作为起点。
