## 这是什么

![一篇文档：右上角是导出、富文本 / 源码切换、分享](/manual/production/wiki.png)

有编辑权就整页可写，没有「编辑」按钮，也没有「保存」按钮——停下来一两秒自动存，顶部显示「已保存」。多人可以同时打开，正在编辑的人会显示在顶部。

## 怎么操作

### 输入

- 直接打字是正文。
- 输入 **/** 弹出块菜单（光标靠近屏幕底部时菜单会朝上展开，不会伸出屏幕）：二级 / 三级标题、无序 / 有序列表、任务列表、引用、代码块、分割线、表格（3×3 带表头）、两栏分栏、高亮块。
- 输入 **[[** 引用另一篇文档：打标题搜索，选中后变成一个可点的链接卡片。写了一个不存在的标题会留作「幻影」链接，之后建了同名文档自动接上。
- 输入 **@** 提到成员，对方收到通知。
- 输入 **#** 引用剧本内容：某一段、某一句台词、某条 Cue，点击直达。
- 粘贴图片直接变成图片块；粘贴飞书文档的内容会保留格式。

### 块的操作

鼠标停在一块上，左侧出现把手：拖动排序；点开菜单可以「转换为」别的类型、上移 / 下移、复制、删除。

- **分栏**：两栏并排，菜单里「增加一栏 / 减少一栏 / 各栏均分」；拖栏间的分隔线调宽度。
- **表格**：选中单元格后，边缘出现插入行 / 列的按钮；可以选中整行、整列、整张表删除。
- **高亮块**：一个带底色的提示框。点左上角的表情换图标：可以搜索（中文、拼音、英文都行），有「最近使用」，也可以选「无图标」。点它左侧的把手打开菜单，一排色块里选一个就换底色，菜单里也有「换图标」。

选中文字弹出格式条：加粗（⌘/Ctrl+B）、删除线、斜体（⌘/Ctrl+I）、下划线（⌘/Ctrl+U）、行内代码，最右边的「A」是颜色。

- **颜色**：点「A」展开两排色块，上排字体颜色（黑、灰、红、橙、黄、绿、蓝、紫），下排背景颜色（灰、红、橙、黄、绿、蓝、紫）。每排最左边带斜线的「A」是「默认」——把颜色去掉，恢复成普通文字；「黑」和「默认」不是一回事，黑是明确选了黑色。
- 从飞书粘贴过来的文字，颜色、底色、下划线会一起带过来，颜色会就近换成上面这几档。
- 导出的文档在别的软件（Obsidian、Typora 等）里打开，颜色和下划线也能正常显示。

### 把任务项变成任务

正文里的任务列表（`/` 菜单里的「任务列表」，每行前面一个勾选框）可以直接变成项目里的任务：

- 光标停在某一行上，这一行上方浮出「☑ 这一行的文字 ｜ 同步任务」。点「同步任务」，选负责人（可不选）和截止时间（可不填），点「创建任务」。
- 任务建好后，这一行末尾多出一个可点的任务标签，显示「任务名 · 状态」；状态在任务面板里推进后，文档里的标签会跟着变。再把光标停上去，浮条变成「打开任务 ↗」。
- 任务那边的详情页底部会列出「相关 Wiki」，能点回这篇文档。
- 一行只能同步一次；这一行还没写字、或者你没有创建独立任务的权限时，「同步任务」按钮是灰的，鼠标停上去能看到原因。
- 删掉任务标签只是解除关联，任务本身还在任务面板里；在任务面板删掉任务后，文档里的标签会显示「已删除」。

### 标签

正文上方「＃ 标签」栏，空格分隔自由手写。树的搜索框能按标签搜。

### 源码模式

顶部「富文本 / 源码」切换。源码模式适合批量粘贴或修复格式。极少数情况下富文本模式会显示不了某些语法（页面会写明「丢失：…」），这时它会自动用源码模式打开——在源码里改就不会丢。

### 相关 Wiki 与关联对象

正文下方：

- **相关 Wiki**：手动把几篇文档关联在一起（「＋ 链接」选一篇，或「＋ 新建文档」）。正文里 `[[引用]]` 过的会自动列出。
- **关联对象**：这篇文档被哪些事件、Cue、任务用到了（它们把这篇挂过去）。

### 导出

顶部「导出」打开打印预览，用浏览器「打印」保存为 PDF。项目开了水印的话 PDF 上带水印。

## 注意事项

- 只读的人也能看到全部内容，只是不能改；评论在文档里暂时没有，讨论走 @ 提及或飞书群。
- `#` 引用的剧本位置是活的：剧本改了，引用跟着走。

## 常见问题

**我的改动被同事覆盖了？**
同时编辑时后保存的内容为准，页面会提示「看到的内容旧」。改之前刷新一下；两个人改同一篇，最好先说一声。
