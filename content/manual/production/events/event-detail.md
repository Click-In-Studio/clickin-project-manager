## 这是什么

点开一个事件，顶部是标题、状态、类型时间地点，然后一排页签：**基本信息 / 事件流程 / 技术提需 / 关联任务与里程碑 / Call Time / 发布 / 报告 / 发布报告**。右上角「关注」，还有「关注者视角」「Call Sheet」「技术需求」三个快捷入口。

![事件详情](/manual/production/event-detail.png)

## 怎么操作

### 基本信息

标题、类型、日期、开始结束、地点、备注、附件。这里还能指定**跟组舞监**（舞台监督 / 助理舞台监督，从有这两个职位的成员里选）。

### 事件流程

那天的时间表：一条一条**流程项**，每条有标题、类型（场景排练 / 服装 / 音响 / 技排 / 会议 / 休息 / 其他）、时间、地点、参与人员、附件。「流程 / 表格」两种看法。

每条流程项也能勾「通知部门」，给部门生成待确认任务。

### 技术提需

对某个部门的要求：「这场要一台雾机」。填需求标题、部门、描述、负责人，可以绑定到某条流程项，可以写「提前分钟」（比如提前 30 分钟到位）。

每条技术需求就是一条**任务**，状态走 待确认 → 待处理 → 进行中 → 完成，在「任务」页也能看到。

### Call Time

每个人几点到。先在流程项里加了参与人员，这里才会出现名单；给每人「设置时间」，可以加备注（舞监台集合）。系统会把明显偏晚的时间标 ⚠。

### 关联任务与里程碑

- 把项目里的**独立任务**关联到这个事件（已经属于别的事件的任务要先在任务详情里解绑）。
- 把事件挂到一个或多个**里程碑**上，计划页汇总用。

### 飞书群

「基本信息」页里可以给事件「创建飞书群」或绑定一个已有的群。解绑不会删群。

## 注意事项

- 编辑事件要先点「进入编辑」，改完「保存」。
- 「技术提需」里的负责人只能由该部门的 POC 或有指派权限的人填，见「任务详情」页。

## 常见问题

**演员看得到技术提需吗？**
看得到列表，但只有相关部门和负责人能改。
