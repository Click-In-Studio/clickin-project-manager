## 本轮 UI / UX 与功能调整

### 1. 资源权限申请

- “临时”权限现在会展开有效期选择：15 天、30 天、90 天、180 天。
- 提交时会把所选天数作为 `ttlDuration` 写入真实审批记录。
- 审批详情会展示申请人姓名和时效；待审批列表也会显示申请人，便于测试多人审批流。
- 状态仍沿用原审批链：直属上级审批 → 资源负责人审批 → 批准/拒绝。

测试路径：`/production/demo-misty-harbor/access-requests`

### 2. 状态与角色颜色

- 修复事件列表虽然定义了状态色、实际却统一渲染成同一棕色的问题。
- 事件状态语义固定为：草稿灰、已发布蓝、已完成绿、已取消红。
- 任务状态沿用并复核：待确认紫、待处理黄、进行中蓝、完成绿；受阻任务为红色提示。
- 审批状态沿用并复核：待审批黄、已批准绿、已拒绝红、已撤回灰。
- 人员页的不同项目角色改为循环使用不同色组，不再全部显示成同一种灰色标签。

测试路径：

- `/production/demo-misty-harbor/events`
- `/production/demo-misty-harbor/tasks`
- `/production/demo-misty-harbor/access-requests`
- `/production/demo-misty-harbor/contacts`

### 3. 置顶公告视觉差分

- 未选中的置顶公告整行使用更深的灰绿色底色、较深边框和左侧强调线。
- 当前选中项仍使用最深色反白，保证“置顶”和“当前选中”是两个可识别层级。

测试路径：`/production/demo-misty-harbor/announcements`

### 4. 项目日历快捷创建

- 每个日期单元格现在都可点击，空日期和有数据的日期均可用。
- 点击日期空白处打开“快捷新建”弹窗，可选择：
  - 事件：填写标题、时间、类型、负责部门；创建后自动生成并绑定默认执行日程。
  - 任务：填写标题、时间、负责部门；创建后同步出现在任务页、月历和甘特图。
- 点击日期内已有事件/任务仍直接进入详情，不会误触快捷新建。
- 支持键盘 `Enter` / 空格打开日期快捷新建。

测试路径：`/production/demo-misty-harbor/planning`

### 5. 事件、任务与计划的数据联动

- 事件页“新建事件”成功后会自动创建一条同时间段的执行日程，并把通知部门绑定到该日程。
- 计划月历、任务甘特、执行日程直接读取事件表、任务表和执行日程表，没有复制一份前端假数据。
- 从事件页或任务页创建的记录，在重新进入或刷新“计划与日程”后会直接出现。
- 从计划月历快捷创建的事件/任务，同样会出现在事件页/任务页。

## 2026-08-17：计划、日历与任务交互增量

### 项目日历

## 2026-08-18：Rundown 表格原位编辑重构

### 调整原因

上一版把人员组、地点和事项时间配置集中放在执行表上方，虽然功能可用，但与飞书多维表格等成熟表格产品的直接操作习惯不一致。本轮将编辑入口全部收回到列头、地点行和事项块本身。

### 人员组列

- 删除执行表上方的大块人员组配置面板。
- 编辑模式下，人员组列头可以直接长按拖动，改变左右顺序。
- 每个列头右侧提供下拉按钮；双击列头也会打开同一个“编辑人员组”面板。
- 人员组面板支持修改名称，混选部门、角色和具体成员，并新增“冻结此列 / 取消冻结此列”。
- 每个列缝及第一列左侧均提供悬停显示的 `+` 按钮，可以直接在该位置插入新人员组。

### 地点分组行

- 编辑模式页头新增“新增地点行”。
- 地点行显示在人员组列头上方，可编辑地点名称和说明。
- 每个地点可以多选人员组；所选人员组会在表头归入对应地点区段，同一个人员组只归属于一个地点。
- 地点行、人员组和事项颜色等视图布局配置保存在当前浏览器，不影响其他测试人员。

### 事项块原位编辑

- 非编辑模式仍保持原有跳转；编辑模式点击任务或日程块只会选中并打开右侧编辑抽屉，不再跳转详情页。
- 编辑抽屉支持修改标题、说明、起止时间、任务状态或日程类型、日程地点、显示人员组和颜色。
- 事项块支持拖放到新的时间格和人员组；拖动上下边缘可以按 15 分钟粒度调整开始或结束时间。
- 时间、标题、说明、状态、日程类型和主责部门等业务信息写回后端；自定义颜色及跨人员组显示属于个人视图配置，保存在浏览器本地。
